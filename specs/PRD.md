# PRD — EdgeGuard 产品需求文档

> **版本**: 1.0.0 | **状态**: 已实现 (MVP) | **最后更新**: 2026-07-26

---

## 1. 产品概述

### 1.1 产品名称
**EdgeGuard** — 边缘智能驾驶安全多模态交互系统

### 1.2 一句话描述
基于边缘-云端混合架构的车载多模态 AI 交互系统：安全功能全本地推理（断网可用），复杂语义理解走云端大模型，手势、语音、面部追踪三通道融合，ReAct Agent 自主决策闭环。

### 1.3 目标用户
- **主驾司机**: 需要实时安全守护、免提车控操作、驾驶行为反馈
- **副驾/乘客**: 空调/音乐/导航等舒适性控制
- **车队管理者**: 驾驶行为分析、安全报告（远期）

### 1.4 核心价值主张
| 痛点 | EdgeGuard 方案 |
|------|---------------|
| 驾驶分心/疲劳无法实时检测 | MediaPipe 468 点面部追踪 + PERCLOS + 四级风险分级 + 即时告警 |
| 车机触屏操作分散注意力 | 手势(16种) + 语音(20+关键词) + LLM 语义理解，免提操作 |
| 隧道/山区无网络时车机变砖 | 安全+手势+关键词全本地推理，离线降级 8 种场景 |
| 传统车机"指令式"交互僵化 | ReAct Agent 自主感知-思考-行动，理解上下文意图 |

## 3. 用户故事

### US-01: 疲劳驾驶守护
> 作为司机，当我长途驾驶开始疲劳时，系统能自动检测并提醒我休息，防止事故发生。

**验收标准**:
- PERCLOS > 0.15 时触发 danger 级别告警
- TTS 语音播报 + 中控屏红色闪烁边框
- 告警记录写入数据库（含 PERCLOS/眨眼率/疲劳分数）

### US-02: 分心检测与恢复
> 作为司机，当我看手机或侧窗超过 3 秒时，系统提醒我注意前方。

**验收标准**:
- 视线偏离 center 超过 3 秒 → 触发 warning
- 视线回正后 1 秒内清除告警状态
- 支持 8 个视线方向：center/left/right/up/down/up-left/up-right/down-left/down-right

### US-03: 手势控制空调
> 作为司机，我可以用手势开关空调，不用触摸屏幕。

**验收标准**:
- Open 手掌 → 开空调 (TurnOnAC)
- Close 握拳 → 关空调 (TurnOffAC)
- 识别置信度 > 0.7 才执行
- 安全告警 severe 级别时阻塞手势指令

### US-04: 语音指令
> 作为司机，我可以用自然语言控制车内功能。

**验收标准**:
- 支持 20+ 本地关键词快速匹配（< 50ms）
- Whisper 完整转写 → DeepSeek LLM 语义理解
- 离线时降级为本地关键词匹配
- "打开空调" / "温度调到24度" / "播放音乐" 等均可识别

### US-05: AI 主动观察
> 作为司机，当我长时间看向窗外美景时，AI 能温柔地问我是否需要停车欣赏。

**验收标准**:
- LLM 分析视线模式 + 持续时间
- 生成温和的中文提醒（15 字以内）
- 正常驾驶不打扰（返回 NONE）

### US-06: 导航与天气
> 作为司机，我可以说"导航到最近的充电站"，系统规划路线并展示天气。

**验收标准**:
- OSRM 免费路线规划（无需 API Key）
- 高德 POI 检索充电站/停车场/景点
- 实时天气 + 驾驶风险建议
- 前端 Leaflet 地图展示路线

### US-07: 驾驶报告
> 作为司机，结束行程后可以查看驾驶行为分析报告。

**验收标准**:
- LLM 生成行程总结（驾驶时长/分心次数/严重告警）
- 安全建议 + 疲劳趋势
- 数据来自 SQLite 持久化记录

## 4. 成功标准

| 指标 | 目标值 | 测量方式 |
|------|--------|---------|
| 摄像头帧率 | ≥ 15 FPS | 实时 FPS 计数器 |
| 面部追踪延迟 | < 50ms | MediaPipe 推理时间 |
| 本地关键词匹配 | < 50ms | 函数计时 |
| 手势识别延迟 | < 100ms | 每 3 帧一次 (~150ms @20fps) |
| API 端点响应 (p50) | < 200ms | FastAPI 内置 metrics |
| LLM 调用超时 | < 10s | httpx timeout |
| 离线可用功能数 | ≥ 8 项 | 断网功能清单 |
| 前端首屏加载 | < 2s | Vite build + Lighthouse |
| 手势识别准确率 | ≥ 90% (16 种手势) | 几何规则 + TFLite 双引擎交叉验证 |

## 6. 约束与假设

### 约束
- DeepSeek API 作为主 LLM 提供商（可切换 OpenAI/Anthropic）
- MediaPipe 模型文件需首次运行时自动下载
- 网易云音乐 API 需本地运行 Node 代理 (localhost:3000)
- 摄像头权限：Windows 下需允许应用访问摄像头

### 假设
- 单摄像头（驾驶员面部），无多摄像头融合
- 每次一位驾驶员，无多人面部追踪
- GPS 由前端浏览器 Geolocation API 提供
- 车控指令为模拟状态（无实车 CAN 接入）
- 音乐播放为模拟状态（无真实音频输出）

## 7. 术语表

| 术语 | 定义 |
|------|------|
| PERCLOS | Percentage of Eyelid Closure — 眼睛闭合时间百分比，疲劳检测金标准 |
| PnP | Perspective-n-Point — 从 2D 特征点 + 3D 模型估计头部 6DOF 姿态 |
| ReAct | Reasoning + Acting — LLM 交替推理与行动的 Agent 模式 |
| Safety Gate | 安全门控 — 根据驾驶员风险等级动态过滤 Agent 可用工具 |
| Edge-Cloud Router | 边缘-云端路由器 — 根据任务复杂度+网络状态选择本地/云端执行 |
| GoalStack | 目标栈 — Agent Core 中管理自主/用户/系统目标的优先级队列 |
| HMI | Human-Machine Interface — 人机界面（中控大屏） |
| DMS | Driver Monitoring System — 驾驶员监控系统 |
