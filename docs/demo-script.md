## 台本正文

### 0:00-0:20｜开场

| 画面 | 语音 |
|------|------|
| 全屏展示 Dashboard 主界面：左侧面板 + 中央地图 + 底部栏 | EdgeGuard，一个跑在本地的边缘智能驾驶安全多模态交互系统。纯 Python 后端加 Vue3 前端，所有 AI 能力离线可用，不需要云端。 |

> 录屏提示：此时摄像头画面显示在地图右上角，展示驾驶员监测已就绪。

---

### 0:20-0:55｜语音车控

| 画面 | 语音 |
|------|------|
| 点击底部"AI 副驾"按钮，右侧滑出 AI 面板 | 先说最实用的——语音和文字都能控车。点开 AI 副驾面板，直接打字或者用浏览器语音识别。 |
| 在输入框输入"打开空调，调到24度"，回车 | 空调控制——意图识别引擎 10 毫秒内走快速规则通道，不经过大模型，所以零延迟。 |
| 空调状态变成 24°C | 可以看到空调面板实时更新。 |
| 输入"调低音量并播放周杰伦" | 再试一个复合指令——调低音量同时播放周杰伦。系统提取到两个动作：音量下调 15 格，搜索并播放周杰伦的第一首歌。注意这个是本地音乐 API 在跑，换歌切歌全程语音可控。 |

> 录屏提示：提前确保网易云 API (localhost:3000) 运行中，否则音乐搜索会走 demo 数据但仍能展示播放状态变化。

---

### 0:55-1:30｜AI 副驾对话

| 画面 | 语音 |
|------|------|
| 输入"今天天气怎么样" | 天气查询——它调了高德 API，返回当前温度、湿度、驾驶建议。 |
| 输入"导航到西湖" | 导航——后端用免费 OSRM 规划驾车路线，地图上实时渲染蓝色路线和预计时间。不用高德 JSAPI，不用 Google Maps，完全免费。 |
| 可以看到地图上出现起点到西湖的路线、时间、距离 | 地图用的 Leaflet 配高德瓦片，路线规划是 OSRM，地理编码走 Nominatim——三件套全免费。 |

> 录屏提示：此时地图右上角的路线指引面板显示分步导航。

---

### 1:30-2:15｜行程规划（核心亮点）

| 画面 | 语音 |
|------|------|
| 点击左侧导航栏"行程"图标，切换到行程面板 | 接下来是重头戏——行程规划。这是最近重点打磨的功能。 |
| 在 AI 面板输入"帮我规划杭州两日游，两个人带老人，一定要去西湖和灵隐寺，不要去宋城，喜欢咖啡和拍照" | 丢一段自然语言进去——注意这里面信息量很大：目的地、天数、人数、老人、必去、避讳、喜好。系统先跑规则提取结构化约束，然后调高德 POI 搜景点搜酒店，最后发给大模型编排日程。 |
| 等 5-10 秒后右侧行程面板更新 | 行程面板展示每一天的时间线：酒店、景点、餐食，带评分和价格。两天按区域划分——第一天西湖周边，第二天灵隐寺方向。注意它主动避开了宋城，因为用户说了不去。 |
| 点击 Day 2 切换 | 切换天数不跳页面，面板内就地刷新。每点一天自动规划到当天第一个景点的导航路线。 |

> 录屏提示：提前确保 AMAP_API_KEY 已配置、大模型 API Key 有效。如果规划耗时较长，可以提前跑好再录制结果面板。

---

### 2:15-2:40｜安全监测

| 画面 | 语音 |
|------|------|
| 点击左侧"安全"图标，切到安全面板 | 最后看一下安全侧——EdgeGuard 的名字里带 Guard，这不是装饰。 |
| 展示安全面板的数据：PERCLOS、眨眼频率、疲劳评分 | 摄像头实时采集面部 468 个关键点，MediaPipe 推理，算出 PERCLOS 闭眼比例、眨眼频率和疲劳评分。 |
| 故意闭眼几秒，触发告警 | 当系统判定疲劳或分心，会自动语音告警，同时记录到数据库。右下角的告警历史可以回溯每一次触发。 |

> 录屏提示：如果没有实体摄像头，可以用手机当外接摄像头，或者提前录一段闭眼视频循环播放。

---

### 2:40-3:00｜收尾

| 画面 | 语音 |
|------|------|
| 切回主界面全景，镜头缓慢拉远 | EdgeGuard 全部跑在本地——FastAPI 后端、Vue3 前端、SQLite 数据库。不需要 GPU，普通笔记本就能跑。AI 部分接的 DeepSeek API，也支持离线降级。 |

| 黑屏 + 项目名 + GitHub 链接 | EdgeGuard——边缘智能，安全随行。 |

## 录前准备清单

- [ ] 后端运行：`uvicorn backend.main:app --host 0.0.0.0 --port 8000`
- [ ] 前端运行：`npm run dev`（frontend 目录）
- [ ] 网易云 API：`localhost:3000` 运行中（可选，无则音乐走 demo）
- [ ] `.env` 中 `AMAP_API_KEY` 已配置（行程规划需要）
- [ ] `.env` 中 `DEEPSEEK_API_KEY` 已配置（AI 对话需要）
- [ ] 摄像头可用（安全监测演示需要，可选）
- [ ] Chrome 窗口 1920×1080，隐藏书签栏
- [ ] 关闭无关通知和弹窗
- [ ] 提前清空聊天记录（刷新页面即可）
